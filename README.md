1. What is the difference between var, let, const?

var: Function scoped. Can be re-declared and updated.

let: Block scoped. Can be updated but not redeclared.

const: Block scoped. Cannot be reassigned.


2. What is spread Operator (...)?

Used to expand elements of arrays or objects.


3. What is the difference between map(), filter(), and forEach()?
map(): Creates a new array. Transforms elements.

filter(): Creates a new array. Returns elements that match condition.

forEach(): Loops through array. Does NOT return new array.


4. What is an arrow function?
Short syntax for functions.


5. What are template literals?
Allow embedding variables in strings using backticks.
